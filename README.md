# Harsh Sharma — Academic Portfolio

Static academic portfolio designed for GitHub Pages.

## Publishing

1. Create a public GitHub repository, preferably `academic-portfolio`.
2. Upload this folder's contents to its `main` branch.
3. In **Settings → Pages**, choose **GitHub Actions** as the source.

The workflow deploys the site and refreshes publications from arXiv weekly.

The public Pages build deliberately excludes CV creation and downloading. GitHub Pages cannot securely restrict a download to one owner; keep that workflow private/local.
